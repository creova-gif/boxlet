# CLI surface & embedding example

CLI surface verifies that the `boxlet` binary and the `examples/embed_run.rs` library embedding example compile cleanly, expose the documented OCI (`create`, `start`, `state`, `kill`, `delete`), V1 `run`, V2 (`init-bundle`, `snapshot`, `diff`, `restore`, `branch-run`), V3 (`list`, `prune`, `audit`), V4 (`doctor`, `eval`), V5 (`image-export`, `image-import`, `microvm-config`), V6 (`audit --prometheus`, `branch-run --max-concurrency`, `eval --max-concurrency`, `init-bundle --rootless`), V7 (`run --io-max`, `branch-run --io-max`, `image-pack`, `image-unpack`), V8 (`run --nofile`, `branch-run --nofile`, `bench`), V9 (`seccomp-export`, `run --mount`, `run --seccomp-profile`, `branch-run --mount`, `branch-run --seccomp-profile`), and V10 (`run --tmpfs`, `run --cmd`, `run -e` / `--env`, `run --cwd`, `branch-run --tmpfs`, `branch-run -e` / `--env`, `branch-run --cwd`) subcommands and flags plus global `--audit-log <PATH>` (ADR-009, ADR-010, ADR-011, ADR-012, ADR-013), execute cross-platform `seccomp-export`, `init-bundle` (including `--rootless`), `image-export`, `image-import`, `image-pack`, `image-unpack` (with `.wh.` whiteout semantics), `microvm-config`, and V2 snapshot, diff, and restore commands end-to-end, and fail closed on unsupported network modes and invalid `--io-max` / `--nofile` / `--mount` / `--tmpfs` / `--env` / `--cwd` rules.

## Sub-features

- `cli-build` compiles `boxlet` (`src/main.rs`) and `examples/embed_run.rs` with zero errors.
- `cli-help` confirms `boxlet --help`, `boxlet run --help` (including `--nofile`, `--mount`, `--tmpfs`, `--seccomp-profile`, `--cmd`, `-e` / `--env`, `--cwd`), `boxlet seccomp-export --help`, `boxlet create --help`, `boxlet list --help`, `boxlet prune --help`, `boxlet audit --help`, `boxlet doctor --help`, `boxlet eval --help`, `boxlet image-export --help`, `boxlet image-import --help`, `boxlet image-pack --help`, `boxlet image-unpack --help`, `boxlet microvm-config --help`, `boxlet bench --help`, `boxlet init-bundle --help`, `boxlet snapshot --help`, `boxlet diff --help`, `boxlet restore --help`, and `boxlet branch-run --help` render the expected flags (`--audit-log`, `--root`, `--cgroup-parent`, `--memory`, `--cpus`, `--io-max`, `--nofile`, `--mount`, `--tmpfs`, `--seccomp-profile`, `--env`, `--network`, `--json`, `--markdown`, `--iterations`, `--warmup`, `--branches`, `--bundle`, `--force`, `--file`, `--prometheus`, `--spec`, `--max-concurrency`, `--archive`, `--layer`, `--tag`, `--layout`, `--driver`, `--mem-mib`, `--vcpus`, `--busybox`, `--hostname`, `--cwd`, `--readonly`, `--rootless`, `--rootfs`, `--out`, `--snapshot`, `--target`, `--promote-winner`, `--cmd`).
- `cli-seccomp-export` executes `boxlet seccomp-export --out <path>` and verifies the exported OCI baseline seccomp JSON contains `"defaultAction"`.
- `cli-init-bundle` executes `boxlet init-bundle --cmd "echo hello" --json <dir>` and `boxlet init-bundle --rootless --cmd "echo rootless-ok" --json <dir>` and verifies `config.json` (with `"uidMappings"` in rootless mode) and `rootfs/etc/hostname` are created in the target bundle directory.
- `cli-v5-v7-image-and-microvm` executes `boxlet image-export`, `boxlet image-import`, `boxlet image-pack`, `boxlet image-unpack` (verifying 2-layer packing and `.wh.<name>` whiteout deletion), and `boxlet microvm-config --driver firecracker --id vm-fc-1 --mem-mib 256 --vcpus 2 <bundle>` and verifies the archive round-trip, OCI Image Layout `OciImageLayoutReport`, and `FirecrackerVmSpec` JSON output.
- `cli-v2-snapshot-diff-restore` executes `boxlet snapshot --rootfs <dir> --out <snaps> --json snap-1`, `boxlet diff --json <snaps>/snap-1 <after>`, and `boxlet restore --snapshot <snaps>/snap-1 --target <after> --json` against a temporary workspace tree and verifies the structured JSON output records the snapshot ID, added and modified relative paths, and an empty post-restore diff (`"added":[]`, `"modified":[]`, `"deleted":[]`).
- `cli-fail-closed` confirms `boxlet run --network bridge /nonexistent` exits non-zero and prints `unsupported network mode` rather than silently falling back to host networking.

## Gotchas

- Live privileged container execution (`sudo boxlet run ...` with `pivot_root`, `unshare`, and `/sys/fs/cgroup/boxlet.slice`) requires a privileged Linux 5.15+ host with unified cgroup v2 controller delegation. Inside unprivileged Docker containers on macOS, live container boot is `verified-unreachable` and is instead verified by the `linux-integration` job in `.github/workflows/ci.yml` on `ubuntu-latest`.
- The internal `boxlet __init` subcommand is intentionally hidden from `--help` output.
